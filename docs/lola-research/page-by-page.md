# Page-by-page consolidation (modern design pass, 2026-10-17)

Pattern applied everywhere (see design-research.md): **summary infographic band at the top → one primary action in the
page head → the working table with fewer columns → reference material in a drawer or a "More details" disclosure.**
Every chart is an SVG with `role="img"` + an aria-label summary and a "Show data" table (WAI complex-images pattern);
colours are Okabe-Ito, and gains/losses always carry a sign (▲/▼, +/−) as well as a colour.
Safety surfaces are unchanged and always visible: topbar KILL SWITCH + Shift+K, PAPER/DEMO badges, step-up on
trading/payments/investor actions, two-person approval on payments, payouts and sanctions clearing.

## Merged / removed
- **Removed:** Home bottom tabs (4 duplicate tables), Home market strip (moved to the Trading world clock), Reports KPI row, the Money "Where things are" table, the Investors custodian and NAV-history tables (now chart data tables).
- **Merged:** Settings › Appearance → Profile. Payments + payouts approvals → a single "Waiting for approval" KPI on Money. Compliance remains the single home of sanctions/FINTRAC/privacy (already merged in the previous pass).
- **Navigation unchanged:** the five sections (Home, Trading, Money, Compliance & reports, Settings).

## Design system
Tokens in `app.css`: spacing `--s1..--s8` (4 px scale), radii `--r-sm/--r/--r-lg`, type scale `--fs-xs..--fs-3xl`, elevation `--elev-1..3`, motion `--ease/--dur`. Fonts: Inter if installed locally, else the system stack (nothing is downloaded). Okabe-Ito chart palette `--c1..--c7` plus `--gain/--loss`. Light and dark themes. `prefers-reduced-motion` disables all transitions. Charts are capped at 1.15× their design width so labels never balloon, and sizing uses the CSSOM because CSP forbids inline style attributes. Contrast is verified by `console/tools/contrast_check.py` (also a console test): all text pairs ≥ 4.5:1 and chart marks ≥ 3:1 in both themes.
